- Website adalah kumpulan halaman dalam suatu alamat internet yang dapat diakses penjelajah web.
- Webapp adalah suatu aplikasi yang diakses menggunakan penjelajah web jaringan seperti internet atau intranet.

Tujuan :

1. Website = menyampaikan suatu informasi kepada pengguna secara statis.
2. Webapp = lebih mengutamakan fitur dan interaksi pengguna: mengirim formulir, menggunakan fitur chat, pembayaran online, dan lain-lain.

Karakteristiknya :

| ***Website*** | ***Web App*** |
| Penggunaan [alamat internet](https://stejproject.github.io/posts/category/wiki-post.html#) sesuai kebutuhan. | Biasanya menggunakan cloud hosting karena penggunaan data yang lebih besar. |
| Konten bersifat informatif dan dapat ditampilkan baik statis maupun dinamis. | Menonjolkan fitur dan interaksi yang fleksibel antar pengguna. |
| Diakses dari browser desktop maupun mobile. | Diakses melalui browser dan dapat digunakan lintas platform. |
| Mengatur navigasi yang user friendly dapat menggunakan CMS dengan mudah. | Sistem atau program dirancang sendiri dengan bahasa pemrograman. |
| SEO friendly dan dapat muncul dalam mesin pencari. | Perlu sign in, segala data pengguna  tidak akan muncul di mesin pencari. |
| Berupa kumpulan halaman yang dapat diakses. | Berupa program tetapi tidak perlu di download /didistribusikan. |
